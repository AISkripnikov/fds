# airMAX Field Tool — Этап 6: диагностика на объекте

**Goal:** ping с телефона и отчёт по линку без неподтверждённых API пушки. Плюс пароль из шаблона при первом входе (спецификация 5.9).

## Решения
- **Ping через TCP-соединение** к 443, затем к 80, сокетом нужной сети телефона (`Network.socketFactory`). ICMP в Android требует root и может уйти в мобильную сеть. Отказ в соединении (RST) считается ответом: хост жив.
- **Отчёт — обычный текст**, отправляется через «Поделиться». Секреты в отчёт не попадают. Вторая сторона моста опрашивается с таймаутом 8 с; если она не ответила, в отчёте «нет данных».
- **Пароль из шаблона** подставляется только по явному нажатию кнопки «Взять из шаблона».
