# airMAX Field Tool — Этап 4: безопасная запись, первый вход, обе стороны моста. План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** настройки становятся редактируемыми. Запись идёт только через резервную копию и тестовый режим с автооткатом. Добавляются мастер первого входа для пушек в заводском состоянии и синхронное применение изменений на обеих сторонах моста.

**Architecture:**
- `SystemConfig` хранит исходные строки без потерь и даёт `with()`, `diff()` и `DangerousKeys`.
- `AirOsClient` получает API тестового режима: `hasTestMode`, `uploadConfig(cfg, testSeconds)`, `confirmTest()` и `cancelTest()`.
- `SafeApply` — чистая машина состояний с подменяемыми часами и проверкой доступности.
- `BridgePlanner` строит пары конфигураций AP PtP / Station.
- `BothEndsOrchestrator` применяет изменения сначала на дальней, потом на ближней стороне.
- UI: правка полей, диалог «было → стало», экран обратного отсчёта, экран первого входа, мастер моста.

**Spec:** `docs/superpowers/specs/2026-11-13-airmax-field-tool-design.md` (разделы 5.4, 5.7, 5.9, 5.10).

## Global Constraints

- Перед любой записью снимается резервная копия: `ConfigBackup` из этапа 2.
- Тест-режим по умолчанию длится 180 с. Кнопка «Сохранить навсегда» появляется, только когда пушка снова доступна. По истечении таймера идёт автооткат.
- Без тест-режима (клиент без `hasTestMode`):
  - опасные поля (IP, маска, шлюз, VLAN, режим, частота, ширина, страна) доступны только для чтения;
  - остальные изменения требуют второго подтверждения.
- Неизвестные ключи и комментарии system.cfg сохраняются при записи байт-в-байт, кроме изменённых строк.
- Конфигурация не попадает в диагностические дампы. `hostToken` остаётся санитизированным.
- Обе стороны моста:
  - запрещено, если хоть одна сторона без тест-режима;
  - дальняя сторона ставится на 300 с, ближняя на 180 с;
  - подтверждение идёт в порядке «дальняя → ближняя».
- Пароль пользователя приложение никогда не подставляет само. Заводские ubnt/ubnt используются только для определения заводского состояния.

## Неподтверждённые эндпоинты (проверить на живых пушках)

| Действие | airOS 8 | airOS 6 |
|---|---|---|
| загрузка cfg | POST `/system.cgi` (multipart `cfgfile`) | POST `/system.cgi` (multipart `cfgfile`) |
| тест-режим | POST `/apply.cgi` `testmode=on&testtime=N` | GET `/apply.cgi?testmode=on` (таймер фиксирован, ≈180 с) |
| подтвердить | POST `/apply.cgi` `testmode=off` (save) | GET `/apply.cgi` |
| откатить | POST `/reboot.cgi` (`reboot=yes`): тестовая конфигурация не сохранена | то же |

Адреса угаданы по веб-интерфейсу. Код изолирует их в двух константах на клиент, чтобы правка была точечной.

## Итог выполнения (2026-11-14)

Сделано в облачной сессии; ветка `claude/charming-ramanujan-0wc3ds`.

Отклонения от плана:
- **Без тест-режима запись выключена целиком** (а не «опасные поля только для чтения + второе подтверждение»). У всех трёх клиентов (airOS 6, airOS 8, демо) тест-режим есть, а пути постоянной записи без отката в API нет. Если появится пушка без тест-режима, это решение надо пересмотреть.
- **airOS 6 на дальней стороне моста:** таймер теста у него фиксирован (≈180 с). Поэтому изменение на обеих сторонах отказывает: дальняя пушка откатилась бы одновременно с ближней. Правило «таймер дальней ≥ таймер ближней + 60 с».
- **Заводское состояние** определяется по входу с ubnt/ubnt. Отдельного признака `FactoryDefault` от пушки нет, класс ошибки оставлен.
- **Хеш пароля** в `users.1.password` пишется как MD5-crypt (`$1$`). Если пушка ждёт другой формат, она не пустит с новым паролем, сохранить будет нельзя, и пушка откатится сама.

Не проверено на железе (проверить первым делом, всё вынесено в константы):
- `WriteEndpoints`: загрузка `/system.cgi` и `/apply.cgi`.
- `BridgeKeys`: ключи `radio.1.mode`, `aaa.*`, `wpasupplicant.*`, VLAN.
- Формат хеша пароля.

Порядок первой проверки: демо-режим → одна пушка, безопасное поле (например `snmp.location`) → откат по таймеру → «Сохранить навсегда» → только потом частота, IP и мост.
