# airMAX Field Tool — Этап 5: восстановление копии, понятные поля, справка по записи. План реализации

**Goal:** закрыть то, что осталось из спецификации v1 после этапа 4:
- восстановление резервной копии с телефона (5.2, «Инструменты»);
- понятные поля в настройках вместо сырых значений `ключ=значение` (5.4);
- справка по записи, мастеру и мосту (5.5).

**Spec:** `docs/superpowers/specs/2026-11-13-airmax-field-tool-design.md` (5.2, 5.4, 5.5, 5.7).

## Global Constraints

- Восстановление копии тоже идёт через `SafeApply`, то есть через тест-режим с автооткатом. Пункт 5.7 разрешает такую запись без защиты, но с защитой безопаснее, поэтому делаем с ней. Перед записью показываем сводку «было → стало».
- Копия, импортированная из файла, проверяется `ConfigBackup.looksLikeConfig`. Не конфигурация — отказ. Копия от другой модели пушки — предупреждение в сводке.
- Редакторы полей не принимают значения, которые airOS не поймёт: номер порта вне диапазона, некорректный IP, ширину не из списка. Неизвестные ключи правятся как текст, как раньше.
- Справка остаётся данными (`HelpContent`), без кода в разметке.

## Tasks

### Task 1: восстановление копии
- [x] `RestorePlanner`: копия → конфигурация для записи; `users.*` берутся из текущей конфигурации пушки, чтобы не сбить пароль случайно; предупреждения (другая модель, другой IP). Тесты.
- [x] `SettingsController.restore(text)`: та же запись через тест-режим, что и у черновика. Тесты.
- [x] Инструменты: у каждой копии кнопка «Восстановить» → сводка «было → стало» → окно отсчёта. Импорт `.cfg` из файла (SAF) в список копий.

### Task 2: понятные поля
- [x] `FieldSpec`: шаблон ключа → тип поля (вкл/выкл, выбор из списка, число в диапазоне, IP, маска, текст) с проверкой и подписями значений («enabled» → «Вкл»). Тесты.
- [x] Окно правки: переключатель, список или поле ввода с проверкой. Карточка показывает понятное значение.

### Task 3: справка
- [x] Поля, которые пишет этап 4: `aaa.*.wpa.psk`, `wpasupplicant.*.psk`, `radio.countrycode`, `radio.*.mode`, `wireless.*.wds.status`, `route.*.gateway`, `snmp.community/location/contact`.
- [x] Статьи: «Безопасная запись и тест-режим», «Мост с нуля: мастер», «Смена канала на обеих сторонах», «Восстановление резервной копии».

### Task 4: проверка и выпуск
- [x] `./gradlew testDebugUnitTest assembleRelease` → `dist/airmax-pole-stage5.apk` (общий ключ подписи), коммит, push.
