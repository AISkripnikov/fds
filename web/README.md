# Беттинг-лаборатория

Статический сайт для личного использования: без сервера, без сборки и без зависимостей.
Чтобы запустить, откройте `index.html` в браузере.

## Разделы

- **Прогноз**: модель Пуассона для футбола. По средним голам (или по xG) считает вероятности 1X2, двойных шансов, тоталов 1.5/2.5/3.5, «обе забьют» и точного счёта. Если ввести коэффициенты букмекера, показывает маржу, перевес (value) и размер ставки по Келли. Кнопкой «+» ставка переносится в трекер.
- **Трекер**: история ставок, проходимость, ROI, максимальная просадка, график банка, фильтр по видам спорта, сравнение ваших оценок вероятности с фактом. Есть экспорт в JSON/CSV и импорт из JSON.
- **Калькуляторы**: конвертер коэффициентов, маржа, критерий Келли, экспресс, симулятор банка методом Монте-Карло.
- **Казино**: слоты, европейская рулетка и блэкджек на виртуальных фишках. У каждой игры показан теоретический и фактический процент возврата.

Данные хранятся в `localStorage` браузера, поэтому периодически делайте экспорт.
